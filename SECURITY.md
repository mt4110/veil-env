# Security policy

## Status

This repository is an unreleased, mock-only prototype. No production security
support or response-time guarantee is currently offered.

## Private reporting

Do not publish vulnerabilities, real secrets, vault URLs, or environment dumps
in public issues. Use GitHub private vulnerability reporting when enabled:
[Report privately](https://github.com/mt4110/veil-env/security/advisories/new).
If that page is unavailable, arrange a private channel with the maintainer
before sending sensitive details. A working private reporting route must be
confirmed before release; no contact email has been invented for this scaffold.

Include affected versions, impact, and reproduction with dummy data.
See [the security model](docs/SECURITY_MODEL.md) for current guarantees and limits.
